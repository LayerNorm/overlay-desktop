# @overlay/llm-gateway

Provider adapters and gateway contracts for LLM calls, including OpenAI, Anthropic, OpenRouter, and Groq.

## Install

For this repository, npm resolves the exact version from the local workspace:

```bash
npm install @overlay/llm-gateway
```

## Usage

```ts
import { generateText } from '@overlay/llm-gateway'
```
